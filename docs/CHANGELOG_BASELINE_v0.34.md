# Changelog — ИИ Паук v0.34

- Версия интерфейса обновлена до v0.34; схема хранилища — 34.
- Добавлены пределы на сохранённые browser tabs/history, bookmarks, terminal history и AI run history.
- Отклоняются HTTP(S) URL с embedded username/password.
- Уточнено позиционирование Паука как будущего отдельного виджета, а Browser — как HTML-прототипа до нативного WebView.
- Выполнен аудит интерфейса, логики, безопасности, архитектуры и критериев реального Android-релиза.
- Исходный v0.33 сохранён в пакете для отката/сравнения.
- Не добавлялись фиктивные функции: реальный PTY, Linux userland, APK и нативный браузер по-прежнему не заявляются готовыми.
