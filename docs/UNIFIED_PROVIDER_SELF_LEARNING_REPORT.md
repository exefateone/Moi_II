# ИИ Паук v0.38 — единая память опыта для всех провайдеров

Дата: 2026-10-17

## Что реализовано

Одна локальная память задач и опыта теперь используется независимо от выбранного источника модели:

- **Локальная LLM (GGUF)** — контекст опыта извлекается из локальной памяти и учитывается в системном контексте.
- **Yandex AI Studio** — прямой чат и планировщик задачи получают ограниченный контекст опыта через общий `SpiderLearningContextCodec`.
- **OpenCode Zen API** — прямой чат и планировщик задачи используют тот же локальный поиск опыта и тот же общий кодек.

Переключение провайдера не создаёт отдельную историю обучения: подтверждённый опыт и оценка задания остаются в общей памяти ИИ Паука и могут учитываться при похожих последующих задачах с другой моделью.

## Как работает самообучение

1. Паук получает задачу и ищет похожие эпизоды в локальной памяти с учётом пространства проекта.
2. При последующих задачах извлечённые подсказки влияют на планирование и формирование ответа.
3. Финальный статус сохраняется отдельно от пользовательской оценки. Проверенный результат имеет более сильное доказательное значение, чем просто сгенерированный ответ.
4. Явные оценки 👍/👎 учитываются как обратная связь. Сама по себе обычная переписка не превращается автоматически в долговременное знание.
5. Память извлекается повторно при следующей задаче; разные поставщики модели получают только ограниченный контекст, без необходимости обучения их параметров.

**Это адаптация поведения на основе памяти, а не изменение весов модели и не fine-tuning.** Подключение API само по себе не обучает удалённую модель.

## Защита данных и границы исполнения

`SpiderLearningContextCodec` ограничивает облачный контекст максимум пятью подсказками и пропускает только известные типы исходов, белый список ID инструмента, короткий безопасный код ошибки и ограниченную оценку уверенности. Локальные тематические токены памяти, полные истории чата, ответы модели, содержимое файлов, сырой вывод инструмента и секреты в этом payload не передаются.

Отдельная функция нейросетевых embeddings — независимая опция, выключенная по умолчанию; она может передавать очищенные тематические токены на настроенный backend только с явным согласием пользователя.

Важно: исполнитель Agent Broker на этом контрольном этапе по-прежнему имеет только один реальный инструмент — `LIST_WORKSPACE_FILES`, который читает список имён файлов. Это не исполнение произвольных команд оболочки и не запись/редактирование файлов. Поэтому Паук может сохранять и учитывать результаты своих доступных заданий, но обработка результатов произвольных shell-команд ещё не реализована и не должна подразумеваться.

## Что не заявляется как подтверждённое

- APK не собран: в среде нет доступных Android SDK/Gradle/NDK.
- Не выполнена проверка на реальном Android-устройстве или эмуляторе.
- Не отправлялись живые запросы к Yandex AI Studio или OpenCode Zen с настоящими учётными данными.
- Не проверялась фактическая генерация локальной GGUF-моделью в этой среде.
- Полный `scripts/verify_project.sh` в этом прогоне не запускался до завершения; его успех не заявляется.

Это контрольная точка исходников и тестовых контрактов, а не собранный релиз APK.
