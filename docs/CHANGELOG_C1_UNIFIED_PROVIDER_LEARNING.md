# ИИ Паук v0.38 — единый цикл памяти для всех LLM-режимов

## Изменения

- Подключил единый `SpiderLearningContextCodec` с ограничением до пяти подсказок и allow-list для outcome kinds/tool IDs.
- Добавил retrieval-подсказки в OpenCode Zen task planner; ранее путь планирования Zen не получал опыт, хотя Yandex и локальная GGUF его использовали.
- Добавил релевантные подсказки из локальной памяти в прямой OpenCode Zen chat; Yandex chat уже передавал такой контекст, локальный чат формирует системный промпт из локальной памяти.
- Сохранил границу приватности: тематические токены не уходят в prompt-память OpenCode Zen/Yandex; отдельная опция embeddings выключена по умолчанию и отправляет очищенные токены только после явного opt-in.
- Уточнил интерфейс и документацию: это адаптация поведения на опыте выполнения проверенных задач и явных оценках, а не изменение весов удалённой или GGUF-модели.

## Границы и безопасность

- Память не может расширить список инструментов или снять подтверждения.
- Успех учитывается лишь после независимой проверки; неизвестный результат не становится успешным.
- Текущий исполняемый инструмент остаётся только `LIST_WORKSPACE_FILES`; arbitrary shell/file writes/external app control не добавлены.
- Никаких полных ответов модели, переписок, содержимого файлов или сырых результатов инструментов новая передача памяти не добавляет.
