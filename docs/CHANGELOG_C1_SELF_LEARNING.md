# ИИ Паук v0.38 — Этап C1: самообучение на истории задач

**Дата:** 16 октября 2026 г.

## Реализовано в исходниках

- Память эпизодического опыта остаётся привязанной к терминальному состоянию задачи и явной оценке пользователя.
- Истории задач с выбранным рабочим пространством сохраняют `workspaceScopeId`; подсказки из workspace A не извлекаются в workspace B. Переход к глобальной памяти допускается только для эпизодов с scope `global`.
- Текущие task store и memory store имеют схему v2 с чтением v1 и переписыванием в актуальном формате при следующем сохранении. Будущая неизвестная схема не должна молча перезаписываться.
- Ранжирование учитывает совпадение темы, доверие к типу исхода/отзыву и мягкое устаревание. Свежесть влияет только на порядок; она не меняет факт независимой проверки.
- Тематические слова используются для поиска на устройстве и не отправляются провайдеру. Backend получает только тип эпизода, разрешённый ID инструмента, безопасный код ошибки и оценку уверенности.
- Android UI связывает задачу с рабочим пространством, выбранным до начала фонового запроса, и блокирует подтверждение, если во время планирования было выбрано другое пространство.
- Документировано исследование и границы самообучения.

## Какую семантику имеем

Под «самообучением» здесь понимается memory-based adaptation: хранение минимальных структурированных эпизодов, извлечение релевантных примеров и передача безопасных подсказок планировщику. Обновления весов модели, fine-tuning и автономного обучения в коде нет.
