# ИИ Паук v0.38 — C1: диагностика памяти и поискового индекса

## Выполнено

Добавлена явная диагностическая панель в нативный центр задач. Она показывает число эпизодов и тематических токенов, размер SQLite-базы памяти вместе с WAL/SHM, число лексических posting-записей, векторов и моделей embeddings, число ожидающих изменений индекса, версии схем, свободное/общее место на томе приложения и статусы `PRAGMA quick_check(1)` для обеих баз.

Диагностика запускается только по действию пользователя на worker-потоке; проверка целостности не выполняется автоматически при каждом запуске. Снимок не содержит путей, целей задач, тем памяти, результатов модели, векторов или секретов. Raw SQLite errors не попадают в UI: доступны только ограниченные статусы проверки.

Текст резюме памяти уточнён: активное SQLite-хранилище не имеет фиксированного лимита по числу эпизодов и не удаляет старые записи автоматически. Физическое место устройства конечное; при сбое записи данные не должны удаляться ради освобождения места.

Добавлен Android instrumentation test для проверки счётчиков, размеров, целостности и отсутствия пути/текста задачи в диагностическом snapshot.
